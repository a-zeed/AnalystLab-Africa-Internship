## 📅 Week 8: Data Analytics Capstone Project

### Project

**Nigeria Development Indicators Analysis**

### Dataset

* World Bank World Development Indicators (WDI)

### Project Overview

The final capstone project analyzed Nigeria's long-term demographic, economic, infrastructure, health, and environmental development trends using selected indicators from the World Bank's World Development Indicators dataset.

The project followed an end-to-end data analytics workflow, including data cleaning, exploratory data analysis, comparative analysis, dashboard development, insight generation, and recommendations.

### Selected Indicators

* Population, total
* Population growth (annual %)
* GDP per capita (current US$)
* GDP growth (annual %)
* Access to electricity (% of population)
* Life expectancy at birth, total (years)
* Forest area (% of land area)
* CO₂ emissions (metric tons per capita)

### Tools

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook
* Microsoft Power BI
* DAX

### Dashboard Components

The Power BI dashboard includes:

* 5 KPI Cards
* Population Growth Trend
* GDP per Capita Trend
* Electricity Access Trend
* Forest Area Decline
* Life Expectancy Trend
* Percentage Change Across Development Indicators
* Year Slicer
* Indicator Name Slicer

### Key Findings

The analysis identified:

* Significant population growth from approximately 45 million in 1960 to over 237 million in 2025.
* Long-term growth in GDP per capita.
* Significant improvement in access to electricity.
* An increase in life expectancy over the available period.
* A decline in forest coverage.
* A slight increase in CO₂ emissions per capita.

The findings highlight both progress and ongoing challenges across Nigeria's demographic, economic, infrastructural, health, and environmental development.

### Project Deliverables

* Python/Jupyter Notebook
* Cleaned Dataset
* Power BI Dashboard
* Final Project Report (PDF)
* Dashboard Screenshots
* Project Documentation
* Demo Video
