# 📊 Data Cleaning & Exploratory Data Analysis (EDA) Project

## 📌 AnalystLab Africa Internship — Week 1–2

This project is part of the AnalystLab Africa Data Analytics Internship Program (Batch B). It focuses on data cleaning, validation, and exploratory data analysis using Python.

Two real-world datasets were used:
- E-commerce Transactions (Online Retail)
- Netflix Movies & TV Shows

---

## 🎯 Project Objectives

- Clean and preprocess raw datasets
- Handle missing values, duplicates, and inconsistencies
- Standardize data formats and structures
- Perform exploratory data analysis (EDA)
- Extract actionable business insights

---

## 📂 Datasets Used

### 1. E-commerce Transactions Dataset
Source: Kaggle Online Retail Dataset  
Focus: Sales, customers, revenue analysis

### 2. Netflix Movies & TV Shows Dataset
Source: Kaggle Netflix Dataset  
Focus: Content distribution, trends, and categories

---

## 🧹 Data Cleaning Process

Across both datasets, the following steps were performed:

- Handled missing values (filled or removed where necessary)
- Removed duplicate records
- Standardized column names and text formatting
- Converted date fields to proper datetime format
- Filtered invalid or inconsistent records
- Created new features for analysis (e.g., revenue, year_added)

---

## 📊 Exploratory Data Analysis (EDA)

### E-commerce Dataset
- Top revenue-generating countries
- Top-selling products
- Monthly sales trends
- Customer purchasing behavior
- High-value customers

### Netflix Dataset
- Movies vs TV Shows distribution
- Top content-producing countries
- Content growth over time
- Most common ratings
- Genre distribution analysis

---

## 💡 Key Insights

- UK is the highest revenue-generating country in the e-commerce dataset
- A small percentage of customers contribute most of the revenue
- Netflix has more movies than TV shows
- Most Netflix content was added between 2016–2020
- Drama and International Movies dominate Netflix content
